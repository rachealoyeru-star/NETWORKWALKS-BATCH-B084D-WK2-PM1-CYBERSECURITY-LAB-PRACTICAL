Project Overview

This project documents my Week 2 practical activities in cybersecurity, focusing on footprinting, reconnaissance, information gathering and network scanning.

The exercises involved using different Kali Linux tools to gather information about a permitted domain and using Zenmap to discover active devices on my own local network.

Tools Used

The following tools were used during the practical exercises:

* WHOIS
* WhatWeb
* Nslookup
* cURL
* Wafw00f
* DNSRecon
* theHarvester
* Maltego
* Zenmap (Nmap GUI)
* Kali Linux
* Windows Command Prompt

Activities Performed

1. Footprinting and Reconnaissance

I used multiple tools to collect publicly available information about the Networkwalks domain.

Activities included:

* Domain registration information gathering.
* Website technology fingerprinting.
* DNS resolution and enumeration.
* HTTP response header analysis.
* Web Application Firewall identification.
* Passive information gathering using theHarvester.
* Graph-based OSINT investigation using Maltego.

2. Network Scanning

I used Zenmap to perform a Ping Scan on my own local network.

The scan identified two live hosts within the scanned subnet. I also generated a network topology graph to visualize the discovered hosts.

Key Findings

* Identified publicly exposed website technologies.
* Retrieved DNS and domain registration information.
* Detected a ModSecurity Web Application Firewall.
* Identified publicly available email information.
* Discovered active hosts on my local network.
* Documented potential security risks and recommendations.

Challenges and Lessons Learned

During the exercises, I encountered issues involving read-only file systems, command-line typing errors and missing API keys.

I learned how to troubleshoot errors, interpret tool outputs and document technical findings.

Security and Authorization Disclaimer

All testing was conducted within authorized educational scope. Network scanning was performed only on my own local network, and the Networkwalks activities were performed with written permission.

TheHarvester demonstration on Microsoft used passive public sources only.

Sensitive details relating to my personal network have been redacted.
